# Kebijakan Privasi · Privacy Policy — BAEUM (배움)

**Berlaku sejak / Effective Date:** 2026-11-27  
**Aplikasi / Application:** BAEUM (`com.armstrang.baeum`)

---

## 🇮🇩 Bahasa Indonesia

**BAEUM (`배움`)** dirancang dengan prinsip ***Offline-First* & Privasi Penuh**. Kami menghormati privasi seluruh pengguna dan tidak mengumpulkan, menjual, atau mengirimkan data pribadi ke server mana pun.

### 1. Data yang Disimpan Secara Lokal di Perangkat Anda
Seluruh progres belajar Anda disimpan **100% secara lokal** di perangkat Android Anda menggunakan SQLite (Room) dan Jetpack DataStore:
- Progres kosakata FSRS (*spaced repetition*), bookmark kosakata & tata bahasa, riwayat kuis, dan simulasi ujian TOPIK/EPS-TOPIK.
- Progres 3 Jalur Silabus (30 pelajaran, stempel `★★★`, Bos Tahap, Brankas Kesalahan, XP, Peringkat, & Stempel Dojang).
- Preferensi tampilan (tema Dark/Light, bahasa terjemahan, ukuran font, kecepatan suara, dan jadwal pengingat belajar).

### 2. Izin Perangkat & Tujuan Penggunaan
- **Mikrofon (`RECORD_AUDIO` — Opsional)**: Hanya digunakan saat Anda secara aktif menekan tombol bicara di *Speaking Studio*, *Pronunciation Lab*, atau sesi *TOPIK Speaking* untuk mengenali pelafalan bahasa Korea melalui layanan *SpeechRecognizer* bawaan perangkat Android Anda. Audio tidak disimpan di server BAEUM.
- **Notifikasi (`POST_NOTIFICATIONS` — Opsional)**: Hanya digunakan jika Anda mengaktifkan Pengingat Belajar Harian di menu Pengaturan untuk menampilkan pengingat lokal di perangkat Anda.

### 3. Cadangan & Penghapusan Data (*User Control*)
- Anda dapat mengekspor seluruh progres belajar kapan saja ke file JSON lokal lewat **Pengaturan → Ekspor cadangan JSON** dan memulihkannya di perangkat lain.
- Menghapus aplikasi atau memilih *Clear Storage* di pengaturan Android akan menghapus seluruh data lokal secara permanen.

### 4. Tidak Ada Pelacakan & Tidak Ada Iklan Pihak Ketiga
BAEUM tidak menanamkan SDK iklan pihak ketiga, tidak melacak lokasi, dan tidak mengirimkan riwayat belajar Anda ke server eksternal.

## 🇬🇧 English Summary

**BAEUM (`배움`)** is an **offline-first** Korean learning application designed with privacy by default:
- **100% Local Storage**: All vocabulary FSRS reviews, 3-track syllabus progress, exam attempts, XP, and settings stay strictly on your Android device (Room SQLite & Jetpack DataStore).
- **Optional Microphone Permission (`RECORD_AUDIO`)**: Requested only when you tap to speak in Speaking Studio / Pronunciation Lab / TOPIK Speaking, processed via Android's on-device/system speech recognition. BAEUM operates no external audio servers.
- **Optional Notifications (`POST_NOTIFICATIONS`)**: Used solely for local daily study reminders when explicitly enabled by you.
- **Zero Ads / Zero Tracking**: No third-party ad networks, no personal data sales, and full user-controlled JSON backup export/restore.
